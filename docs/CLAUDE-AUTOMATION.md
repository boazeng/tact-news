# Claude במקום גרוק — תכנון (טרם בוצע)

סטטוס: **תכנון בלבד, 2026-10-28 עד 2026-10-30.** שום דבר עוד לא נבנה. גרוק ממשיך לפרסם כרגיל.
המטרה: התוכן היומי מוכן אוטומטית ע"י Claude, **בלי מחשב אישי דולק**.

## היום — מה רץ איפה
```
  גרוק (ענן xAI)  ──חומר──►  NotebookLM (ענן גוגל)
       │                           │
       │ ניוזלטר, קישורים          │ פודקאסטים + תקצירים (גרוק מעביר לאתר)
       ▼                           ▼
  ┌──────────────────────────────────────┐
  │  האתר — Mac mini, Docker (פורט 8110)  │  ← לא AWS
  └──────────────────────────────────────┘
       ▲                       ▲
     דפדפן            אפליקציית iOS (mobile-app\tack-news)
```
האתר רק מקבל, שומר ומגיש — לא מייצר תוכן.

## היעד — חלוקת עבודה
```
  Claude Routine (ענן Anthropic, לפי cron)
     חוקר → כותב → POST /api/publish ─────────►  האתר (Mac mini, ללא שינוי)
                                                    ▲
  Claude Cowork (על ה-Mac mini, דפדפן Chrome)       │
     גיליון מהאתר → NotebookLM → הורדה → /api/publish/audio
```

| חלק | איפה | למה |
|---|---|---|
| טקסט: ניוזלטר, קישורי פודקאסט, YouTube, מדריכים, מאמרים | **Routine בענן** | יציב, לא תלוי במחשב, לא נשבר משינויי ממשק |
| אודיו דרך NotebookLM | **Cowork על ה-Mac mini** | החלק היחיד שצריך דפדפן |

## החלטות
- **הפודקאסטים נשארים ב-NotebookLM** (החלטת בועז, 2026-10-30) — איכות גבוהה, כלי שבנוי לזה. **לא** TTS של ElevenLabs.
- האתר לא משתנה — אותו API שגרוק משתמש בו.

## ממצאים
- **Routine בענן:** cron ב-UTC (ישראל = UTC+2 בחורף / +3 בקיץ), מינימום פעם בשעה. יש לו רק connectors של claude.ai — **לא** ה-`/mcp` של האתר ⇒ מפרסם ב-REST (`POST /api/publish`, אותה לוגיקה כמו `/mcp`).
- **גישת רשת:** סביבת הענן מוגבלת כברירת מחדל ⇒ צריך Full, או לאפשר את `tact-news.newavera.co.il`.
- **טוקן:** `TACT_NEWS_PUBLISH_TOKEN` כמשתנה סביבה בהגדרות הסביבה (לא בטקסט ההוראות). הרשאת פרסום בלבד.
- **User-Agent חובה** בכל בקשה — בלי זה Cloudflare חוסם (403/1010).
- **NotebookLM הצרכני — אין API.** NotebookLM Enterprise (Google Cloud) מאפשר ליצור סקירה קולית ב-API (`notebooks.audioOverviews.create`), אבל לפי התיעוד **אין הורדה של הקובץ ב-API** — רק בממשק. לכן האודיו = אוטומציית דפדפן (Cowork).
- **Cowork:** רץ רק כשהמחשב ער ו-Claude Desktop פתוח ⇒ על ה-Mac mini (דולק תמיד). לוודא בגרסה הנוכחית איך מתזמנים בו.
- ב-`GROK-PROMPT.md` YouTube/מדריכים נבחרים "לפי מה שבועז הגדיר לך" — זה בזיכרון של גרוק. **צריך לכתוב את הקריטריונים** בהוראות ל-Claude.

## מה צריך לבנות
1. `docs/CLAUDE-PROMPT.md` — גרסה של `GROK-PROMPT.md` ל-Claude: `GET /api/topics` במקום `list_topics`, `POST /api/publish` במקום כלי MCP, אימות בסוף. הסוכן קורא אותה מהריפו בכל ריצה.
2. בהגדרות הסביבה ב-claude.ai/code: רשת + הטוקן.
3. Routine (שעות — בועז מחליט).
4. על ה-Mac mini, לאודיו: כניסה אוטומטית למשתמש, ללא שינה, Claude Desktop + Chrome + Claude in Chrome, Chrome מחובר ל-Google של NotebookLM, משימה מתוזמנת ב-Cowork.

## סיכונים
- שינוי בממשק של NotebookLM שובר את האוטומציה עד תיקון.
- התחברות Google פגה ⇒ 2FA ידני.
- NotebookLM מפיק כמה דקות לכל תחום — עם 5 תחומים הריצה יכולה להתקרב לשעה.

2. במקביל: בדיקה ידנית אחת שCowork מפעיל את NotebookLM מקצה לקצה על ה-Mac mini.
