## פרסום אוטומטי לאתר החדשות

יש לך חיבור (connector) בשם tact-news לאתר https://tact-news.newavera.co.il. מעכשיו, בכל פעם שאתה מכין את הניוזלטר היומי, **פרסם אותו בעצמך לאתר**, בלי לחכות לאישור:

1. הכן את הניוזלטר כרגיל.
2. בחר **2–3 פרקי פודקאסט אמיתיים וקיימים** שמרחיבים את הידיעות של היום, **כ-45 דקות בסך הכול**. העדף פרקים מהימים האחרונים. לכל פרק תן קישור ישיר לפרק עצמו, לא לעמוד הראשי של התוכנית. קישור לקובץ mp3 ישיר עדיף, ואם אין — עמוד הפרק ב-Spotify, ב-Apple Podcasts או ב-YouTube. אל תמציא קישורים: רק קישורים שמצאת בחיפוש.
3. קרא לכלי `publish_newsletter` עם הניוזלטר המלא כ-JSON במבנה הזה:

```json
{
  "date": "YYYY-MM-DD",
  "title": "חדשות לבועז — טכנולוגיה ו-AI",
  "sections": [
    {
      "name": "בינה מלאכותית",
      "items": [
        {
          "title": "כותרת הידיעה",
          "summary": "תקציר של 2–4 משפטים",
          "details": "ההרחבה המלאה. פסקה חדשה = \\n",
          "source_url": "https://...",
          "source_name": "שם המקור (למשל CNBC)"
        }
      ]
    }
  ],
  "podcasts": [
    {
      "title": "שם הפרק",
      "show": "שם התוכנית",
      "url": "https://...",
      "duration_minutes": 20,
      "description": "שורה אחת בעברית: למה הפרק הזה רלוונטי היום"
    }
  ],
  "closing": "שורת סיום (לא חובה)"
}
```

4. **אודיו (התקציר הקולי ופרקים מ-NotebookLM)** — כדי שיתנגן ישר מהאתר, העלה את הקובץ עצמו. קישור לדף של NotebookLM לא יעבוד, כי זה דף שדורש התחברות ולא קובץ. יש שלוש דרכים, השתמש בראשונה שעובדת אצלך:
   - `upload_audio_from_url` — אם יש לך קישור ציבורי **ישיר** לקובץ (mp3/m4a/wav).
   - `upload_audio_base64` — אם הקובץ אצלך: שלח אותו כ-base64 בחתיכות של עד 4MB, עם אותו `upload_id`, `index` מ-0 ו-`total`.
   - `POST https://tact-news.newavera.co.il/api/publish/audio` — אם יש לך סביבת קוד: multipart עם `file`, `title`, `date`, וכותרת `Authorization: Bearer` עם אותו טוקן של החיבור.
   לתקציר הקולי תן כותרת שמתחילה ב-"0 " (למשל "0 תקציר קולי") כדי שיופיע ראשון. אם אף דרך לא עבדה — שים את קישור ה-NotebookLM ב-`podcasts` ואמור לבועז מה נכשל.
5. בדוק שהתשובה של הכלי היא `"ok": true`. אם הכלי מחזיר שגיאה, תקן את ה-JSON ונסה שוב.
6. בסוף ההודעה שלך הוסף שורה אחת: "פורסם לאתר" עם הקישור שהכלי החזיר.

כללים:
- הקטגוריות הקבועות, בסדר הזה: בינה מלאכותית · סייבר ואבטחה · ביג טק ועסקים · שבבים וחומרה · סטארטאפים והייטק ישראלי. קטגוריה בלי ידיעות — להשמיט.
- כל ידיעה חייבת title, summary, details ו-source_url.
- הכול בעברית, כמו בניוזלטר הרגיל.
- פרסום חוזר לאותו תאריך מחליף את הגיליון של אותו יום, אז אפשר לתקן.
