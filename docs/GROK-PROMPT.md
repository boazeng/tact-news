מעכשיו, בנוסף לניוזלטר היומי, החזר את הניוזלטר גם כקובץ JSON אחד בבלוק קוד, במבנה הזה בדיוק:

```json
{
  "date": "YYYY-MM-DD",
  "title": "חדשות לבועז — טכנולוגיה ו-AI",
  "sections": [
    {
      "name": "בינה מלאכותית",
      "items": [
        {
          "title": "כותרת הידיעה",
          "summary": "תקציר של 2–4 משפטים",
          "details": "ההרחבה המלאה. פסקה חדשה = \\n",
          "source_url": "https://...",
          "source_name": "שם המקור (למשל CNBC)"
        }
      ]
    }
  ],
  "closing": "שורת סיום (לא חובה)",
  "notebooklm": "חומר הרקע המלא ל-NotebookLM להפקת הפודקאסטים (לא חובה — אפשר גם בנפרד)"
}
```

כללים:
- JSON תקין בלבד בתוך הבלוק: מירכאות כפולות, בלי הערות, בלי פסיק אחרי האיבר האחרון. מירכאות בתוך טקסט (כמו ארה"ב) — לכתוב עם \" .
- הקטגוריות הקבועות, בסדר הזה: בינה מלאכותית · סייבר ואבטחה · ביג טק ועסקים · שבבים וחומרה · סטארטאפים והייטק ישראלי. קטגוריה בלי ידיעות — להשמיט.
- כל ידיעה חייבת title, summary, details ו-source_url. אם אין מקור ישיר — הקישור הטוב ביותר שיש.
- הטקסט בעברית, כמו בניוזלטר הרגיל.
